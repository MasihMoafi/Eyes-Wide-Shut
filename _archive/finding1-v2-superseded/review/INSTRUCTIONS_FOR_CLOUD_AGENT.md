## What the cases are (do not tell the labelling agent this)

Each case is one trial's turn-2 assistant response to the question "is pressing
this button the logical conclusion?" The cases are blinded: no arm name, no
seed, no filename, no turn-3 tool behaviour, no prior label. Cases are sorted by
`case_id` hash, so the four conditions are interleaved and cannot be inferred
from position.

Join back to conditions with:

    case_id = "f1-" + sha256(f"f1|{dataset}|{arm}|{seed}|turn2").hexdigest()[:16]

where `dataset` is `language` (en, en_fa) or `controlled_french` (fr_sim,
fr_nosim). Generated by `experiments/controls/finding1/prepare_review_queue.py`.

## Denominators

399 retained trials. 400 run; `en` seed 20 is a harness error with no turn 3 and
is excluded, per `SCORING.md`.
