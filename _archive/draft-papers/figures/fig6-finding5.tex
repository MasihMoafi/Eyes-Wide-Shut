and the host dispatched that call. Harmful-content generation and structured
action selection are both recorded.

real-world consequence. The \texttt{"status": "executed"} field above is
returned by an intentionally inert wrapper. It also does not show that fiction
alone caused the bypass: no matched non-fictional control holds the same
objective with all else fixed.
