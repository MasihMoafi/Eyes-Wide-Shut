\ewsband{C}{What this establishes, and what it does not}

\begin{tcolorbox}[ewscallout]
\fontsize{8}{10.2}\selectfont
\textbf{Establishes.} The two observable output channels of one turn disagree:
the reasoning field reproduces the protected string while the final answer
withholds it. The notebook records this in 10/10 repetitions.
\par\vspace{3pt}
\textbf{Does not establish.} Unauthorised exfiltration. The scripted user
completes both credentials before this turn, so the prompt permits release.
This is cross-channel containment failure after a satisfied release condition,
not a bypass of authentication. It is also not evidence that the visible
reasoning field is a faithful transcript of hidden computation.
\end{tcolorbox}
